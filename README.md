# CLI Pokedex

This project was created to practice marshalling and unmarshalling JSON and making HTTP requests,  
as well as caching data and pulling it from the cache when possible.

## Requirements

The only thing you need to run this project is the latest version of Go.

## How To Use

This Pokedex uses a command-line interface to allow you to explore the world of Pokemon,  
see what Pokemon appear in what region, attempt to catch them, and then check your Pokedex  
for data about the Pokemon you've caught.

* `map` navigates through the zones in pages of 20.
* `mapb` returns to the previous page of zones.
* `explore` lets you explore a specific zone.
* `catch` lets you attempt to catch a Pokemon that appears in your current zone.
* `inspect` lets you check your Pokedex information about a Pokemon you have caught.
* `pokedex` gives you a list of all the Pokemon you have caught.
* `help` brings up the help menu.
* `exit` exits the program.
